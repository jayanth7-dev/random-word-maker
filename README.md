Random Word Maker

A simple desktop application built with Python and PyQt5 that generates random words.

Features
Generates random words with a button click
Three independent word generators
Simple PyQt5 graphical user interface
Lightweight beginner-friendly Python project
Preview

The application displays three random-word sections. Click any Click Me button to generate a random word in its corresponding section.

Requirements
Python 3
PyQt5
Installation

Clone the repository:

git clone https://github.com/jayanth7-dev/random-word-maker.git
cd random-word-maker


Install the dependency:

pip install -r requirements.txt


Run the application:

python main.py

How It Works

The application stores a list of words and uses Python's random.choice() to select a random word whenever one of the buttons is clicked.
